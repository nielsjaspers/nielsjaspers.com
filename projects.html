projects.

a small and growing list of things i've built, mostly because i needed them and the existing options didn't fit.

01

freeflow

a simple space for unfiltered writing. supports timers for timed sessions. no styling, no fancy features, just undistracted writing. no sign-in, so everything stays on device.

source visit
02

manipic

a set of image manipulation utilities, inspired by quickpic. built because i needed a tool for specific tasks. nothing fancy, just enough for my needs.

source visit
03

at-transfer

a simple peer-to-peer file transfer tool built on top of the AT Protocol. log in with your bluesky app password and send files to other users. mobile and enterprise networks restrict p2p, so it's mostly useful on a local network, but it was a fun experiment in combining the AT Protocol with p2p technology.

source visit
04

cli-sky · archived

a command-line tool in go to interact with bluesky. since archived. it was a fun project to test the AT Protocol inside a terminal tool: logging in, renewing sessions, and posting, all with simple commands.

source
05

cls (command line share)

my first attempt at a command line tool. a fast, secure file sharing cli written in go, using TLS for quick and private file transfers on a local network.

source
06

gradient background generator

i needed some gradient backgrounds, so i made a tool for it. html, css, typescript, runs fully on-device. nothing more to say about it, it just generates custom gradients.
